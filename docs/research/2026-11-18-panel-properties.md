## Version discrepancies

The moving 5.x documentation currently names `databaseNotificationsPollingInterval`, `requestPasswordResetRouteSlug`, and `resetPasswordRouteSlug`. The [v5.9.0 notification concern](https://github.com/filamentphp/filament/blob/v5.9.0/packages/panels/src/Panel/Concerns/HasNotifications.php) instead declares `databaseNotificationsPolling`; the [v5.9.0 authentication concern](https://github.com/filamentphp/filament/blob/v5.9.0/packages/panels/src/Panel/Concerns/HasAuth.php) declares `passwordResetRequestRouteSlug` and `passwordResetRouteSlug`. See [#163](https://github.com/Azab-Inc/filament-theme-builder/issues/163), [#171](https://github.com/Azab-Inc/filament-theme-builder/issues/171), and [#172](https://github.com/Azab-Inc/filament-theme-builder/issues/172). Do not generate names from the moving docs for 5.9 without verifying compatibility.

## Important behavior for specifications

- `darkMode(false)` disables dark mode; `themeSwitcher(false)` only hides the switcher; forced dark mode is an argument of `darkMode`. The default theme mode is separately configured. Preserve independently authored light/dark theme data. [Styling](https://filamentphp.com/docs/5.x/styling/overview#dark-mode).
- `globalSearch`, `userMenu`, and `databaseNotifications` each have placement options; the 5.x docs describe topbar-to-sidebar fallback if the topbar is disabled. Test combinations with existing FTB-055 rather than inventing a replacement. [Search](https://filamentphp.com/docs/5.x/resources/global-search), [user menu](https://filamentphp.com/docs/5.x/navigation/user-menu), [notifications](https://filamentphp.com/docs/5.x/notifications/database-notifications).
- Tenancy requires application model contracts, explicit `canAccessTenant` checks and appropriate model scoping; merely setting `tenant()` does not secure an application. Tenant middleware may need persistence across Livewire requests. [Tenancy security](https://filamentphp.com/docs/5.x/users/tenancy#tenancy-security).
- Many documented values are closures, application classes, routes, providers or hooks, not CSS. Define an authorized host integration and faithful export strategy before treating those controls as implementable; never execute imported arbitrary code as a preview shortcut. [Panel configuration](https://filamentphp.com/docs/5.x/panel-configuration).
