# FTB-008 Raw Inspector and FTB-004 Vanilla CSS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a secure typed raw-element Inspector layer and minimal vanilla CSS export while preserving semantic overrides, preview security, persistence, history, and existing demo behavior.

**Architecture:** Extend canonical theme state from V3 to V4 with a separate `rawOverrides` collection keyed by selector. Keep raw validation and CSS generation pure in builder services, then mirror validation at the iframe bridge boundary. Reuse the existing Inspector protocol, managed style element, Pinia history, persistence, JSON export, and real Filament fixture.

**Tech Stack:** Vue 3, TypeScript, Pinia, Vitest, Laravel Blade bridge, PHPUnit, Pint, PHPStan, Compose Playwright.

**Spec:** `TICKETS.md#ftb-004`, `TICKETS.md#ftb-008`, `SPECS.md` §§9 and 24.

## Global Constraints

- No new dependencies.
- Preserve unrelated `.gitignore`, existing plans, prototypes, and worktree changes.
- Keep semantic `overrides` isolated from `rawOverrides`.
- Reject arbitrary CSS declarations, scripts, `url()`, at-rules, unsafe selectors, and unsafe values.
- Preserve iframe origin/source validation and normal preview navigation.
- Implement minimal vanilla CSS only; do not implement FTB-024 or FTB-025.
- Write failing tests before production code and run builder, PHP, and Compose Playwright verification before completion.
