# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The primary users are developers and designers working together on Filament themes. They use the builder to shape, inspect, and refine a theme before implementation or handoff.

## Product Purpose

The product is a visual theme builder for Laravel Filament. It makes theme creation and review possible through an interactive builder rather than requiring every visual decision to be made directly in code.

## Positioning

Its differentiator is a visual workflow for creating and previewing Filament themes while keeping the resulting theme decisions usable by developers.

## Operating Context

Users work through builder surfaces for foundations, semantic components, visual prototypes, branding, and raw inspection. The workflow supports iterative comparison and refinement of theme values.

## Capabilities and Constraints

- Preserve existing product behavior and terminology when changing the interface.
- Treat the current builder workflows and Filament terminology as established product context.
- The repository contains a Vue builder application under `builder/`.

## Product Principles

- Make visual theme decisions inspectable.
- Support collaboration between design intent and implementation detail.
- Keep theme controls connected to realistic Filament UI previews.
- Preserve the vocabulary and workflows users already rely on.
